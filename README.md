# workbench

A desktop app for agent-driven mechanical design.

The owner inspects CAD parts, assemblies and MuJoCo simulations in 3D, comments, decides and
explores what-ifs. A Claude Code agent does the engineering in a project's own code and drives
the app through the `wb` CLI.

See `docs/plan.md` for the design and `CLAUDE.md` for how to work in this repo.
